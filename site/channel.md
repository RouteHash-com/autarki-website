# Another node

> Incoming room for a Lightning node that is not the Autarki page in front of you. Blake2b XBT, then SHA-256 BTC. The price is sats.

The page is [https://autarki.app/channel](https://autarki.app/channel).

## The wallet already opens it

This page is for a node that is not the Autarki wallet in front of you. A home node you open from a phone, or another Blake2b or SHA-256 node, can buy incoming room from a node other people operate. The wallet button says Use Autarki's pool. If Autarki is already open in front of you, stay there. Press Use Autarki's pool when a payment needs a channel.

- The best way to create the channel is Autarki. Install Autarki. The wallet opens a pool channel when a payment needs one.
- Fill Send only moves your own sats into the Lightning wallet. That move does not open a channel.
- Someone sitting at that computer does not need this website. Use Autarki's pool there does the same open.

## This door is for a node outside that page

Blake2b has no public place to buy incoming room. Magma cannot open a Blake2b channel. SHA-256 BTC already has Magma, so this page, for BTC, is for someone who wants a channel to that node, at the price the node charges.

- Blake2b XBT. Paste one line with @ in it from that Blake2b node. The pool opens toward that node after the payment is tied to it.
- SHA-256 BTC. Paste one line with @ in it from that SHA-256 node. The Blake2b name does not open a BTC channel.
- No stablecoin. No monthly fee. The price is sats. A dollar figure is not the size.
- The bought channel does not hold a shipment. When the seller holds a float, the coins sit on the seller's own node until Mark received. Autarki cannot move them. Without that float, the shipment is not held.
- An Autarki user can still use this page. The channel can land on an Autarki node.

## The price is sats

The price is 1,000 sats plus 1 percent of the room. The node charges it. Autarki does not collect it.

- Room stays between 20,000 and 1,000,000 sats, in steps of 100.
- 20,000 sats of room costs 1,200 sats. 100,000 sats of room costs 2,000 sats. 1,000,000 sats of room costs 11,000 sats.
- A size is for sale only when that pool can open it. This page does not see the pool's open room, so it shows the price and does not take the fee.
- A bare fee does not name the node. The amount names the room size. The pool opens toward a node only after the payment is tied to that public name.
- Autarki does not take a cut of the catalog price. The node charges the Lightning costs: routing at most 1,000 sats, and room of 1,200 sats for 20,000 or 2,000 sats for 100,000. A room fee is what that node charges for incoming room. Autarki does not collect it.

## Paste only the public name

1. Open Autarki, then Settings, then Coin Nodes, then Lightning. Press Show this node's public name.
2. Copy the line with @ in it for the chain you want. Paste the Blake2b line on Blake2b XBT. Paste the SHA-256 line on SHA-256 BTC.

Do not paste a login.

- The public name is the one line with @ in it.
- The Blake2b lndconnect link and the SHA-256 API address are logins for another Autarki. They do not open a channel. Do not paste them here, and do not paste the API password.
- 127.0.0.1 and `<your public IP>` from those logins are not the public name.

Incoming room shows on that node, and a purchase from that wallet can use it. An iPhone, or another Autarki with Use other Autarki Lightning nodes on, uses that room only while it is pointed at that same home node. The phone does not receive the channel itself.

The home node has to stay on until the channel confirms, and afterward while a payment uses it.

Checking a name does not send it. This site does not sign in, does not keep the name, and does not take the fee.
