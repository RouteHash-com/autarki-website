# Classifieds

> Ship pays with Lightning. With a float, the coins sit on the seller's node until Mark received. The named referee decides and does not hold the coins.

The page is [https://autarki.app/classifieds](https://autarki.app/classifieds).

## Ship it. The coins wait.

Ship pays with Lightning. With a float, the coins sit on the seller's node until Mark received. Autarki does not hold them.

- A separate public board from the shop catalog. Off until Enable Classifieds under Settings. A new wallet leaves them off.
- Goods, services, rentals, jobs, giveaways, and personals. Same key as the shop. No store required.
- The buyer chooses Pick up or Ship. There is no default.
- Pick up pays on-chain or with Lightning, in XBT or in BTC. Pick up does not wait.
- Ship pays with Lightning only. No on-chain. AMD or Intel only. Off on a Raspberry Pi and on Umbrel arm64.
- A shipped order is not held until a float is set aside. Provide a float records the choice. It does not send coins.
- Before payment, each side names one public name, or nobody. After Not received, that person gives one decision: pay the seller, or send the coins back.
- The referee does not hold the coins. They stay on the seller's node.
- 14 days at home, or 28 days overseas. If the buyer does nothing, the seller is paid when the hold ends, only while that wallet is on.
- Four public signs. None is required to buy or sell. Nobody types a count. No star.
- A 64-bit Android phone can install its own copy. A phone on the same network can still open your computer's page.

## Post an ad

A signed note from any Nostr key shows on the wallet board. The poster does not need an Autarki wallet. A Nostr extension in the browser signs the note. This page does not ask for a secret key. The note is published to the relay the notice board reads. A note sent only to some other relay never arrives. Classifieds has to be turned on, and the wallet has to be unlocked, or that board stays hidden.

- A title is one line, at most 80 characters. A missing title is dropped.
- A listing id is 1 to 256 characters with no spaces. The same key and the same id replace the note.
- The body is at most 4000 characters.
- A price in whole sats of XBT or BTC can be paid when the note also carries that chain's silent-payment code. This page cannot make the code.
- A dollar amount, a fraction, or any other currency is shown as text and cannot be paid.
- Ship appears when the note names a public Lightning node for a chain that has a code.
- Mark sold or Cancel this ad hides the note. A person a wallet has blocked or ignored is hidden on that wallet only.
- This page checks the note before it is signed. A note this board does not carry is not sent.
- This site does not keep the key or the note.

Published classifieds are on the [notice board](https://autarki.app/notice-board.md).
