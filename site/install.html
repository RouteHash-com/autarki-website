Install

Install it on your computer.

AMD and Intel include Lightning. A Raspberry Pi runs the wallet, the shop, Nostr, and on-chain payment, and leaves Lightning off. A 64-bit Android phone can install the same program and keep its own wallet.

Which machine

Install on Machine Lightning
StartOS AMD or Intel. File autarki_x86_64.s9pk. This release is 0.1.0:31. Included. Blake2b Lightning and SHA-256 Lightning.
StartOS Raspberry Pi. File autarki_aarch64.s9pk. This file is still the previous page. Off. The wallet, the shop, and on-chain payment still run.
Umbrel The AMD or Intel image from the RouteHash community store. The listing is 0.1.19. Included.
Umbrel arm64, including a Raspberry Pi. This image is still the previous page. Off.
Ubuntu The image in the repository, autarki_ubuntu_amd64.tar. Included. It is the AMD or Intel build.

The public download is release 0.1.0. Source is github.com/RouteHash-com/autarki. Install starts the wallet. It does not open a Lightning channel.

Android

Version 0.1.0 (17) is the same program as the computer. The phone needs a 64-bit processor and Android 8 or newer. It keeps its own wallet file. Restoring the 24 words onto the phone makes a second copy. The same 99 digits do not rebuild a wallet. This phone adds its own randomness. The 24 words shown once are the only backup.

Download autarki-android.apk from release 0.1.0 and allow the phone to install it. Check that file against SHA256SUMS from the same release. This file installs over the previous signed 0.1.0 package. A phone that already has 0.1.0 (1) has to uninstall that copy before this one will install. Or request access. Sign in with a Google account. Firebase emails the install.

Lightning for Blake2b XBT bitcoin and SHA-256 BTC bitcoin is in this package. A phone that only opens your computer's page holds no seed. That path is still there.

iPhone

Version 0.1.0, build 4, is the same wallet and shop. It keeps its own wallet file. Restoring the 24 words onto the phone makes a second copy.

This build does not start Lightning. Use other Autarki Lightning nodes stays on, for another Autarki that stays running.

It is not on the App Store. Enter your email and request an invite. If the form does not send, write to apple@autarki.app with the subject Apple Autarki Tester Request. Install TestFlight, then open the invite when it arrives.

StartOS

  1. Download the package that matches the server from release 0.1.0.
  2. Check it against SHA256SUMS from that same release.
  3. Sideload the file and install Autarki. Install does not ask for Bitcoin Knots or Bitcoin Core.
  4. Open Autarki. Create the wallet. Write the 24 words on paper before you leave that screen.

Before you make a wallet, the page on your computer opens on Shop. After a wallet exists, it opens on Receive.

Umbrel

This site does not give you an Umbrel file. Add the RouteHash community store, then install Autarki. That store is not the official Umbrel App Store. Load the image that matches the machine.

  1. In Umbrel, open Settings, then App stores, then Add a community app store.
  2. Paste https://github.com/RouteHash-com/umbrel-store.
  3. Install Autarki.

The store listing is github.com/RouteHash-com/umbrel-store.

Ubuntu

An Ubuntu server with Docker uses autarki_ubuntu_amd64.tar from the same release. The steps are on the Ubuntu page in the repository.

Check the download

Put SHA256SUMS from the release in the same folder as the file you downloaded. Then run:

sha256sum -c SHA256SUMS --ignore-missing

The line for your file ends in OK when the download matches.

Help

Bug reports go to the RouteHash Discord channel #autarki. The support page is that contact. The privacy policy covers the keys, the camera, location, relays, and nodes. The page can show English, Español, Português, Français, or Deutsch. The choice stays in your browser. The 24 words stay the English list. Amounts stay in sats. The dollar hint stays US dollars or Canadian dollars.

Paper, Ink, and Console on this website are the same three contrasts as the wallet. Paper is the default. The choice stays in your browser.
