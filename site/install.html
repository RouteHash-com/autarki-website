Install

Install it on your computer.

23 November 2026. Lightning for XBT and for BTC is in the AMD and Intel StartOS package, the Ubuntu image, the Umbrel amd64 image file, and Android. The Umbrel community store, a Raspberry Pi, and Umbrel arm64 leave Lightning off. On-chain still works there. Prepare payment no longer stops with "The payment was not prepared." Used Lightning addresses stay hidden unless that method is selected. After you broadcast, Spendable here keeps this wallet's own change until the normal balance can be shown. A refused broadcast says why. A mining reward that is too young to send stays out of Spendable here.

Which machine

Install on Processor Machine Lightning
StartOS x86_64 AMD or Intel. File autarki_x86_64.s9pk. This release is 0.1.0:51. Included. Blake2b Lightning and SHA-256 Lightning.
StartOS aarch64 Raspberry Pi. File autarki_aarch64.s9pk. This release is 0.1.0:51. Off. The wallet, the shop, and on-chain payment still run.
Umbrel amd64 The amd64 image file on release 0.1.0. The same page as the Ubuntu image. Included.
Umbrel Store listing The community store. The listing is 0.1.34. A wallet from 0.1.33 stays. Off. On-chain still works.
Umbrel arm64 Including a Raspberry Pi. Off. On-chain still works.
Ubuntu amd64 The image in the repository, autarki_ubuntu_amd64.tar. Included. It is the AMD or Intel build.

The public download is release 0.1.0. Source is github.com/RouteHash-com/autarki. Install starts the wallet. It does not open a Lightning channel.

On a phone

  • A phone on the same network can open your computer's page. That phone holds no seed.
  • Installing the Android app, or the iPhone app, makes its own wallet file. Restoring the 24 words onto the phone makes a second copy. The 24 words are shown once. They are the only backup.

Android

Version 0.1.0 (76) is the same program as the computer. The phone needs a 64-bit processor and Android 8 or newer. The same 99 digits do not rebuild a wallet. This phone adds its own randomness.

Google Play offers open testing. Join from the Play Store at https://play.google.com/store/apps/details?id=app.autarki, or from the web at https://play.google.com/apps/testing/app.autarki.

Or download autarki-android.apk from release 0.1.0 and allow the phone to install it. Check that file against SHA256SUMS from the same release. This file installs over the previous signed 0.1.0 package. A phone that already has 0.1.0 (1) has to uninstall that copy before this one will install. Or request access. Sign in with a Google account. Firebase emails the install.

Lightning for XBT and for BTC comes with this package.

iPhone

Version 0.1.0, build 20. The same page as the computer and Android packages.

This build does not start Lightning. It uses Lightning on another Autarki that you keep running. Use other Autarki Lightning nodes stays on.

It is not an App Store listing. Join the public TestFlight test from this page. Install TestFlight, then open https://testflight.apple.com/join/2WMBzSpM.

StartOS

  1. Download the package that matches the server from release 0.1.0.
  2. Check it against SHA256SUMS from that same release.
  3. Sideload the file and install Autarki. Install does not ask for Bitcoin Knots or Bitcoin Core.
  4. Open Autarki. Create the wallet. Write the 24 words on paper before you leave that screen.

Before you make a wallet, the page on your computer opens on Shop. After a wallet exists, it opens on Receive.

Umbrel

The amd64 image file on release 0.1.0 includes Lightning. The community store is a separate listing, and it is not the official Umbrel App Store.

  1. In Umbrel, open Settings, then App stores, then Add a community app store.
  2. Paste https://github.com/RouteHash-com/umbrel-store.
  3. Install Autarki.

The store listing is github.com/RouteHash-com/umbrel-store.

Ubuntu

An Ubuntu server with Docker uses autarki_ubuntu_amd64.tar from the same release. The steps are on the Ubuntu page in the repository.

Check the download

Put SHA256SUMS from the release in the same folder as the file you downloaded. Then run:

sha256sum -c SHA256SUMS --ignore-missing

The line for your file ends in OK when the download matches.

Help

Bug reports go to the RouteHash Discord channel #autarki. The support page is that contact. The privacy policy covers the keys, the camera, location, relays, and nodes. The page can show English, Español, Português, Français, or Deutsch. The choice stays in your browser. The 24 words stay the English list. Amounts stay in sats. The dollar hint stays US dollars or Canadian dollars.

Paper, Ink, and Console on this website are the same three contrasts as the wallet. Paper is the default. The choice stays in your browser.
