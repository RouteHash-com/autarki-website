Classifieds

Find a referee.

Both sides of a classified shipment name the same person before payment, or both name nobody. Copy a public name from here. The referee does not hold the coins. Autarki does not check the Discord message. A shop sale does not name a referee. A store stall does not name one.

Search.

Either side can decline until both sides name the same person. Decline does not move coins.

  • The list stays empty until you type.
  • Linking a Discord name does not by itself list them. A nostr name can be listed with no Discord name. Wallet 0.1.0 cannot ask to be found.
  • The card shows the nostr nickname. It shows the small Discord name when they linked one. A space in that Discord name is ignored.
  • A card with a Discord name has Open the Discord message. A member of that server can open it. Autarki does not check it.
  • Received shipments and Known by stay on the stall and the ad. They are not listed here.
