Board rules

What a public note can carry.

These rules cover a shop note and a classified. This page is https://autarki.app/board. It is dated 10 November 2026. Autarki is not directed at children.

Accept before the first note

A shop note and a classified are public. Anyone who can read the relay can read them. The wallet asks you to accept these rules before the first one is saved. Not now does not post.

The note is for goods, a service in person, a rental, a job, a giveaway, or a personal notice.

What the board does not carry

A note does not carry sexual content, a threat, a weapon, an illegal drug, or a promise of profit.

Child sexual content is forbidden. That includes any sexual content involving a person under 18. Do not post it, ask for it, or link to it.

The wallet refuses a note that asks for one of those before it is sent. The sentence is “This note cannot be posted. It asks for something this board does not carry.” The same check runs when a wallet reads a classified, and on this site before a Nostr extension is asked to sign. A note already on a relay that asks for one of those is left off the board.

Report and block

In the wallet, Report this ad and Report this shop send a note to the Autarki relay. The reasons are spam, sexual content, a threat, a weapon, an illegal drug, or something else. Block this seller stays on that computer. Ignore stays on that computer.

A report is sent to the Autarki relay. The ad stays on the board. Block and Ignore hide it on that device only.

The relay can still store the original note until the person who posted it deletes it, or the relay operator removes that row. Autarki cannot pull a public note off a relay it does not run. Questions go to Discord #autarki.

No platform. Just the sale.

Autarki is a beta. It runs on your computer. A 64-bit Android phone can install its own copy. A phone on the same network can still open your computer's page.
